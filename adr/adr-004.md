# ADR-004: `UNKNOWN` Parameters

[ADRs](./README.md)

## Status

✅ **Adopted**

> Principle is in use in the ecosystem, or the feature has been implemented in the example implementation

## Context

Some functions do not care whether their input is `ISOLATED` or `SHARED`. Values of either kind should be usable.

## Decision

When returned from a function call, every structure must have a reference-count of at least 1 (for the assumed recipient) plus whatever other references remain after releasing the local variables of the function.

If an `ISOLATED` value is known to have no other references beyond the recipient, it can be flagged as `UNIQUE` instead of just `ISOLATED`. One way to ensure this is to “mutate” it (i.e. `ENSURE_UNIQUE`) before returning.

`SHARED` data cannot be returned as `UNIQUE`.

## Rationale

1. Some functions do not care whether their input is `ISOLATED` or `SHARED`. Values of either kind should be usable.

## Alternatives Considered

- IEEE 754
- Represent constants symbolically or as infinite sums

## Consequences

### Positive

- Can support arbitrary size and precision.

### Negative

- It is unclear how to specify precision need or how numbers should behave when assigned.
- Mathematical constants cannot be stored with an infinite decimal expansion so what precision to store is unclear.
