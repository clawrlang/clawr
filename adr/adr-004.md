# ADR-004: `UNKNOWN` Parameters

> Status: ✅ Adopted

## Context

Some functions do not care whether their input is `ISOLATED` or `SHARED`. Values of either kind should be usable.

## Decision

A function can declare parameters without specifying semantics. Such parameters have `UNKNOWN` isolation, are read-only, and cannot be assigned to other variables.

> [!note]
> The rules themselves are defined in the specification: [The `(default)` Semantic Mode](../spec/language/semantics/function-parameters.md#the-default-semantic-mode). This ADR records only the reasoning.

## Rationale

1. Some functions do not care whether their input is `ISOLATED` or `SHARED`. Values of either kind should be usable.

## Alternatives Considered

- Require all parameters to have explicit isolation levels
- Default (no-keyword) parameters to `const` semantics
