# ADR-023: `integer` Division

[ADRs](./README.md)

## Status

✅ **Adopted**

> Principle is in use in the ecosystem, or the feature has been implemented in the example implementation

## Context

Binary operators should include division (`/`) and modulus (`%`).

The behaviour when rounding is needed varies depending on language. Some programming languages truncate towards zero. Other languages round down (mathematical floor) even if the result is negative.

## Decision

Division applies to numeric operands (`integer` and `real`). When both operands are `integer`, the result is also `integer`. If at least one operand is `real`, the output is `real`.

The divisor may not be zero. A zero divisor yields an undefined result according to mathematics.

The result is rounded down ($\left\lfloor {n \over d} \right\rfloor$). If the result is negative it will round to a larger magnitude.

The modulus operator (`%`) returns the remainder after integer division: $n - \left\lfloor {n \over d} \right\rfloor \cdot d$.

## Consequences

### Negative

- Might contradict expectations.

### Positive

- Makes sense mathematically.
- Allows the modulus output to rotate through the range $\left [ 0, |n| \right )$ without jumps.

## Alternatives Considered

- Truncate towards zero.
