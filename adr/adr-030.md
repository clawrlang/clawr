# ADR-030: The `real` Datatype: `real big`

> Status: ❌ Rejected

## Context

This proposal considered adding `real big` as an arbitrary-precision decimal type.

## Decision

`real big` is not part of the design. Every `real` has a declared finite precision, while its magnitude may grow as far as available memory permits. Arithmetic rounds after each operation as specified by [ADR-027](./adr-027.md), avoiding the need for exact arbitrary-precision intermediates.
